Privacy Policy

Andra YouTube Growth Automation

Last Updated: October 5, 2026

1. Overview

The Andra YouTube Growth Automation system ("System") is a personal automation tool designed to help manage and optimize your YouTube channel and connected social media accounts. This Privacy Policy explains how the System handles your data.

2. Data Collection

The System collects and processes only the data necessary to operate:

  • YouTube Analytics: Video performance metrics, viewer demographics, traffic sources, watch time, retention curves
  • YouTube Account Data: Channel information, video metadata, playlist data, content IDs
  • TikTok Account Data: Video performance metrics, follower counts, engagement statistics
  • Authentication Tokens: OAuth refresh tokens for continued API access
  • Operational Logs: Workflow execution history, analysis results, optimization recommendations

3. Data Use

Collected data is used exclusively for:

  • Analyzing channel performance and identifying growth opportunities
  • Generating automated recommendations for content optimization
  • Preparing and publishing content to your social media accounts
  • Tracking performance metrics and measuring the effectiveness of optimizations
  • Improving the System's algorithms and recommendations
  • Maintaining system logs and operational records

Data is never used for:

  • Third-party marketing or advertising
  • Selling or sharing with external companies
  • Creating profiles about you beyond what's necessary for the System
  • Any purpose other than operating this personal automation system

4. Data Sharing

Your data is shared only with:

  • YouTube (Google): When reading analytics and publishing content (via official YouTube API)
  • TikTok: When reading analytics and publishing content (via official TikTok API)
  • GitHub: Encrypted storage of authentication tokens in private repository (GitHub Secrets)

Data is never shared with:

  • Advertising networks
  • Data brokers
  • Social media platforms beyond what's necessary for posting
  • Analytics services (except platform-native analytics)
  • Any third-party service without explicit authorization

5. Data Storage

Location:

  • GitHub (encrypted private repository) - United States
  • Google Cloud (YouTube API) - varies by configuration
  • Local machine during daily automation runs

Duration:

  • OAuth tokens: Kept indefinitely for continuous operation (you can revoke anytime)
  • Operational logs: Retained for 90 days for debugging and optimization
  • Video analytics: Retained as long as videos exist on your channel
  • Performance snapshots: Retained for historical analysis and learning

6. Security

Your data is protected by:

  • OAuth 2.0 with PKCE for secure authentication
  • GitHub Secrets for encrypted credential storage
  • HTTPS-only communication with platform APIs
  • Minimal data retention (delete when no longer needed)
  • No passwords stored (token-based authentication only)

7. User Rights

You have the right to:

  • Access: Request what data the System holds about your account
  • Revoke: Disconnect the System from your YouTube/TikTok accounts at any time (revoke OAuth tokens)
  • Delete: Request deletion of logs and cached data (System will purge retained records)
  • Control: Enable/disable specific features and data collection within the System

8. Third-Party Services

The System uses these third-party APIs:

  • YouTube Data API v3: For analytics and publishing (Google's Privacy Policy applies)
  • TikTok API: For publishing and analytics (TikTok's Privacy Policy applies)
  • GitHub: For token storage in private Secrets (GitHub's Privacy Policy applies)

Please review each platform's privacy policy for their data handling practices.

9. No Tracking or Telemetry

The System does not:

  • Track your browsing outside the System
  • Send telemetry to external services
  • Build profiles about you beyond system operation
  • Use cookies or pixel tracking
  • Collect any data beyond what's necessary to operate

10. Data Deletion

To delete your data:

  1. Revoke OAuth tokens in your YouTube/TikTok account settings
  2. Contact: andra.kiirkivi@gmail.com to request deletion of retained logs
  3. All cached tokens and logs will be purged within 7 days

11. Children's Privacy

This System is not designed for or targeted at children under 13. By using the System, you represent that you are 13 years or older.

We may update this Privacy Policy at any time. Changes will be posted here with an updated "Last Updated" date. Continued use indicates acceptance of the updated policy.
