🔐 TikTok Sandbox Integration Demo

Real OAuth 2.0 + Content Posting API Flow for App Review

0Configuration (One-Time Setup)

Get your TikTok App Credentials
Before starting the demo, you need your TikTok Sandbox app credentials:
  • Client ID - from TikTok Developer Console → Apps → Your App → Basic Information
  • Client Secret - from same location (keep this SECRET, never share)
  • Sandbox User Account - test TikTok account for demo (created in Developer Console)
BEFORE YOU START:
1. Go to https://developer.tiktok.com/console/apps
2. Select your app (or create one if needed)
3. Copy your Client ID and Client Secret
4. Create a Sandbox User account in Developer Console
5. Have these values ready (you'll need them below)

1Initiate Real TikTok OAuth Authorization

What happens
You will be redirected to TikTok's real login page where you'll authenticate with your Sandbox user account and approve the app's requested permissions:
  • user.info.basic - Read your account information
  • video.upload - Upload videos
  • video.publish - Publish videos
  • video.list - List your videos
YOU NEED TO:
1. Click the "Start Real Authorization" button below
2. You'll be redirected to TikTok's login page
3. Sign in with your Sandbox user account
4. Review and approve the requested permissions
5. TikTok will redirect you back here with an authorization code

2Capture Authorization Code from Callback

What happens
After you approve on TikTok's login page, TikTok redirects back to our callback URL with a real authorization code in the URL parameter. This code is single-use and expires quickly.

3Exchange Authorization Code for Real Tokens

What happens
The authorization code is exchanged for:
  • Access Token - Short-lived (1 hour), used to make API calls on behalf of the user
  • Refresh Token - Long-lived, used to get new access tokens when the current one expires
YOU NEED TO DO:

This step requires your Client Secret (which must never be exposed to frontend). You have three options:

Option A (Recommended for Demo): Use curl with your Client Secret
curl -X POST https://open.tiktokapis.com/v2/oauth/token/ \ -H "Content-Type: application/x-www-form-urlencoded" \ -d "client_id=YOUR_CLIENT_ID" \ -d "client_secret=YOUR_CLIENT_SECRET" \ -d "code=AUTH_CODE_FROM_STEP_2" \ -d "grant_type=authorization_code"
Replace:
  • YOUR_CLIENT_ID - Your app's Client ID
  • YOUR_CLIENT_SECRET - Your app's Client Secret
  • AUTH_CODE_FROM_STEP_2 - The code from Step 2

4Real Content Upload & Publishing

What happens
With a valid access token, you can now upload and publish real videos to the TikTok Sandbox account.
YOU NEED TO DO:

Step 4A: Upload Video
curl -X POST https://open.tiktokapis.com/v2/post/publish/upload/ \ -H "Authorization: Bearer ACCESS_TOKEN_FROM_STEP_3" \ -F "video=@/path/to/your/video.mp4" \ -F "type=video/mp4"
Response will include: upload_id (needed for step 4B)
Step 4B: Publish the Video
curl -X POST https://open.tiktokapis.com/v2/post/publish/action/publish/ \ -H "Authorization: Bearer ACCESS_TOKEN_FROM_STEP_3" \ -H "Content-Type: application/json" \ -d '{ "media_type": "UPLOAD_ID_FROM_STEP_4A", "post_info": { "desc": "Demo video from Andra YouTube Growth automation", "disable_comment": false, "disable_duet": false, "disable_stitch": false } }'

5Verify Video Published

What to record for TikTok App Review
After completing all 4 steps, your video will appear on your Sandbox TikTok account's profile. For the screen recording:
  • Screenshot or show the authorization code from Step 2
  • Show the tokens returned from Step 3 (access_token and refresh_token)
  • Show the upload_id from Step 4A
  • Show the successful response from Step 4B with the published video ID
  • Navigate to your Sandbox account profile to show the video is actually there
