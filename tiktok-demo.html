🎬 TikTok Integration Demo

Complete OAuth 2.0 Authorization + Content Posting Flow for App Review

Phase 1: User Authorization (TikTok Login Kit)

1 User Initiates Authorization
User clicks "Authorize TikTok" button to grant the app permission to:
  • Read user account information (user.info.basic)
  • Upload and publish videos (video.publish)
  • Access video analytics (video.list)

Phase 2: TikTok Redirects with Authorization Code

2 Receive Authorization Code
After user approves on TikTok's login page, TikTok redirects to our callback with an authorization code. This happens automatically via the redirect URL we configured.

Phase 3: Exchange Code for Tokens

3 Backend Token Exchange (Server-Side)
Server exchanges authorization code for access and refresh tokens. This happens server-side using the Client Secret (never exposed to frontend).

Phase 4: Publish Content

4 Upload Video to TikTok
With the access token, the app can now upload and publish videos to the user's TikTok account.

Complete Demo Flow Timeline

1
User clicks "Authorize TikTok"
Redirects to TikTok login page with client_id, scopes, and redirect_uri
2
User logs in and approves scopes
User sees what permissions app is requesting and approves
3
TikTok redirects with auth code
Callback URL receives authorization code: https://andraks-bit.github.io/andra-youtube-growth/tiktok-callback.html?code=XXXX
4
Server exchanges code for tokens
Backend posts code + client_secret to /oauth/token/ endpoint, receives access_token and refresh_token
5
Store refresh token securely
Refresh token stored in GitHub Secrets for long-term automation access
6
Use access token to post videos
Call /v1/post/publish/ API with access_token to publish videos to user's account
